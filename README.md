## GPU preboot probe

The local `out/oneplus13t/boot/stage7-gpu-probe/boot.img` candidate adds an optional **A830 GPU probe (read only)** menu entry and disables the menu countdown. It pairs a rebuilt UEFI with the same Build 63 kernel, trust cache, RAM Data and ADT as the tested resource-only image. The probe is a separate UEFI application; booting the normal XNU entry does not invoke it. GPU acceleration remains unfinished.

Temporarily load this image with `fastboot boot`, select the probe with the volume keys and power key, then photograph the register rows and `Result` line. `Result=0` means the conditional SMMU register reads completed; `Result=1` means the power/reset/clock prerequisites were absent, so no SMMU register was accessed. Neither result establishes GMU startup or rendering. If it stops at `reading`, capture that pending address. The adapter cannot recover a bus fault. Press a volume key after the result to return, then select the normal XNU entry and check UI, touch and `CPU reg=8 online=8`. This candidate has not been booted during development.

The probe reads 11 GPUCC registers and, only when CX and its clocks are already available, five SMMU registers. It changes no GPU power, clocks, reset, firmware or mappings. Its UEFI mappings use Device attributes; the separate GX controller remains disabled and unprobed. The portable policy test covers 128 power/reset/clock combinations, every read-failure position and invalid SMMU IDs. Firmware compilation, memory-map checks and payload readback are host checks.
